# Раскрой проката

Веб-страница для раскроя линейного проката (уголок, швеллер, профильная труба, полоса и т. п.) на штанги заданной длины. Загружаете Excel со списком деталей и получаете карту раскроя с минимальным количеством штанг, а также готовый Excel-файл для цеха.

Всё считается в браузере: файлы никуда не отправляются, сервер не нужен.

## Как пользоваться

1. Откройте страницу и перетащите файл `.xlsx` в поле «Исходная таблица». Можно и просто скопировать ячейки в Excel и нажать Ctrl+V на странице.
2. Проверьте длину штанги и ширину реза. Если в таблице есть строка вида «ширина реза 4 мм, длина штанги 11950 мм», значения подставятся сами.
3. Отметьте профили, которые нужно считать. Для отдельного профиля можно задать свою длину штанги.
4. Нажмите «Скачать Excel».

## Формат таблицы

| ширина реза 4 мм, длина штанги 11950 мм | | |
|---|---|---|
| **уголок 75х6** | **уголок 63х5** | **ГНЗ 140*4** |
| 2048*3 | 1436 | 4262 |
| 2403 | 1476*4 | 7581 |
| … | … | … |

- Каждая колонка — один профиль: название в заголовке, ниже длины деталей в миллиметрах.
- `2048*3` — три детали по 2048 мм, число без `*` — одна деталь. Одинаковые длины из разных строк складываются.
- Строка с параметрами необязательна.

Примеры входных файлов лежат в папке [`example/`](example/).

## Что в результате

- **Итого** — сводка по профилям: штанг, метраж, отход, и доказан ли минимум. Длина штанги и пропил стоят в жёлтых ячейках: если их изменить, остатки на листах пересчитаются формулами.
- **Лист на каждый профиль** — схемы реза: сколько штанг резать по схеме, длины деталей с одной штанги, остаток. Ниже идёт проверка комплектности: нужно / нарезано / разница.

Пропил учитывается на каждую деталь, то есть с запасом.

## Как это считается

Задача одномерного раскроя (cutting stock) решается в три шага:

1. Генерация столбцов: симплекс-метод плюс задача о рюкзаке дают нижнюю границу — меньше штанг быть не может.
2. Округление по остатку строит целочисленный план.
3. Локальная перепаковка доводит план до нижней границы.

Если количество штанг совпало с границей, на странице и в Excel стоит отметка «меньше нельзя».

## Файлы

- `index.html` — страница
- `assets/solver.js` — алгоритм раскроя (работает в Web Worker, интерфейс не подвисает)
- `assets/xlsxio.js` — чтение и запись `.xlsx` (на основе [JSZip](https://stuk.github.io/jszip/))
- `assets/app.js`, `assets/style.css` — интерфейс
- `test/solver.test.js` — проверка на реальных заказах: `node test/solver.test.js`

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save. Через 1–2 минуты страница откроется по адресу `https://<пользователь>.github.io/raskroy-master/`.
